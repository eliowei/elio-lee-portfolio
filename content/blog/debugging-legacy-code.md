接手既有系統時，最大的困難往往不是技術，而是「不確定改這裡會影響哪裡」。

尤其遇到不熟悉的程式碼，看到問題就直接修改，很容易只修到表面，卻沒有真正解決問題。

後來我發現，面對這類情況，比起急著找出哪一行程式碼有問題，更重要的是先建立一個清楚的除錯流程：**重現、定位、歸因、修復、防範**。

這篇整理我在維護既有系統時，會使用的幾個思考方向。

## 一、重現：先讓問題穩定發生

無法穩定重現的問題，修好了也無法證明修好。

所以第一步不是修改程式，而是先確認問題發生的條件：

- 哪個頁面、什麼操作順序、什麼資料？
- 只發生在特定瀏覽器、螢幕尺寸或登入身分嗎？
- 能不能縮小到最小重現範例（Minimal Reproduction），拿掉不相關的程式碼，讓問題還在，代表範圍縮對了。

如果問題只在特定條件下發生，就要把這些條件記錄下來，避免每次測試都使用不同情境，最後無法判斷修改是否真的有效。

## 二、定位：用二分法縮小範圍

確認問題可以重現後，接下來才是找出問題發生的位置。

我通常會從瀏覽器 DevTools 開始：

- **Console**：先看有沒有錯誤或警告，它們常直接指出方向。
- **Network**：確認請求有沒有送出、狀態碼、回傳資料是否符合預期。
- **Elements**：查看實際套用的 CSS，以及被控制的規則是否被覆蓋。
- **Sources**：在可疑位置設中斷點，或用 Event Listener Breakpoints，在特定事件發生時暫停。

不要一開始就把整個專案的程式碼都看過一遍。

可以先確認問題發生在前端互動、API 請求，還是資料回傳之後，再逐步縮小範圍。

## 三、歸因：用假設驗證，不要憑猜測

介面行為問題常見的原因，可以先對照檢查：

| 現象 | 常見原因 | 驗證方式 |
| --- | --- | --- |
| 彈窗或外層介面立即關閉，或關不掉 | 事件冒泡或事件順序，點擊後上層攔截 | 在 capture 階段記錄事件路徑 |
| 元件值沒有更新 | 響應性失效（解構、非響應式物件） | 在 DevTools 檢查該值是否仍具響應性 |
| 樣式改了沒效果 | 選擇器優先權較低，或被相同權重樣式覆蓋 | 在 Elements 面板查看被覆蓋的規則 |
| 浮層被遮住 | stacking context 讓 `z-index` 失效 | 檢查祖先元素是否有 `transform`、`opacity` 等 |
| 偶發錯誤 | 非同步時序或請求競態 | 加上時間戳記紀錄，並比對順序 |

例如要確認是哪一層攔截了點擊，可以在 capture 階段觀察事件路徑：

```js
document.addEventListener('click', (e) => {
  console.log('capture:', e.target, e.composedPath())
}, true)
```

這樣可以先確認事件實際經過哪些元素，再決定是否需要調整事件處理方式。

重點不是看到某個現象就直接套用熟悉的解法，而是先提出假設，再透過工具驗證。

## 四、修復：最小範圍，並評估影響面

找到原因後，也不代表可以直接大幅修改。

修改前先回答三個問題：

1. 這段程式碼還有哪些地方會用到？（全域搜尋、查看引用）
2. 修改會改變哪些既有行為？
3. 有沒有更小的改法？例如修正元件本身，而不是在每個呼叫端補一次。

既有系統通常沒有完整測試，因此修改後更需要手動走過「會受影響的流程」，而不只是驗證被回報的那一個情境。

例如修正一個共用元件的事件行為，就不能只確認目前頁面正常，也要確認其他使用這個元件的頁面沒有受到影響。

## 五、防範：讓同樣的問題不再發生

問題修好之後，還可以再想一步：有沒有辦法讓它下次更容易被發現？

- 補一個能重現原問題的測試；沒有測試環境時，至少把重現步驟寫進 PR 說明。
- 能用工具擋下的，就改成規則，例如 ESLint 規則或元件的 props 限制。
- 把相關記錄在程式碼註解或文件中，寫的是「為什麼這樣做」，而不是「做了什麼」。

這些做法不一定要一次全部完成，但能逐步降低相同問題再次出現的機會。

## 這次學到的事

維護既有系統時，最容易遇到的情況，就是看到問題就想著趕快修好。但實際上，如果沒有先弄清楚問題發生的條件，以及原本程式的執行流程，很容易只修到表面，甚至影響其他原本正常的功能。

這次整理下來，我發現除錯不只是找到錯誤發生的位置，更重要的是理解它為什麼發生，以及修改之後會不會帶來其他影響。

尤其是面對不熟悉的程式碼時，先縮小問題範圍、確認原因，再決定怎麼修改，往往比急著動手更有效率。

對我來說，維護既有系統也是一種理解程式設計的過程。除了讓問題恢復正常，也要思考有沒有辦法讓相同的問題不再發生。
